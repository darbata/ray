# ray

Building ray tracer to achieve the following:
1. consolidate understanding of Linear Algebra (currently studying university unit)
2. understand structure of C++ programs (e.g. CMake, software architecture etc.)

Built directly from Linear Algebra concepts such as vectors and matrix transformations. Then 'rendered' by writing to `.ppm` formatted file.
